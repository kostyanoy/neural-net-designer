**NeuralNet Designer** — визуальный конструктор, среда обучения и экспорта нейронных сетей. Позволяет проектировать архитектуру графическим методом (Drag & Drop), настраивать датасеты и гиперпараметры, обучать модели в реальном времени с мониторингом метрик, а также экспортировать готовый Python-код и веса модели.

## Ключевые возможности
- **Визуальный редактор графов** на базе `NodeGraphQt` с валидацией архитектуры, проверкой связности и автоматическим расчётом размерностей тензоров.
- **Мониторинг в реальном времени**: графики Loss/Accuracy, таблица метрик, логи, прогресс эпох и батчей.
- **Работа с датасетами**: предустановленные (MNIST, Iris), препроцессинг (нормализация, стратификация, split).
- **Гибкая настройка обучения**: оптимизаторы, LR, L2-регуляризация, функции потерь, выбор метрик, CPU/CUDA.
- **Экспорт проекта**: генерация Python-кода (модель, датасет, обучение) через Jinja2 + Black, сохранение весов `.pth`.
- Undo/Redo, автосохранение, сериализация в `.nnd` (JSON).

## Инструкция по установке
### 1. Общие зависимости
1.1. Убедитесь, что у вас установлен **Python 3.10**.  
```bash
python --version
```
1.2. Скачайте или склонируйте репозиторий.  
```bash
git clone git@github.com:kostyanoy/neural-net-designer.git
cd neural-net-designer/
```
1.3. Создайте и активируйте виртуальное окружение
```bash
python -m venv venv
.\venv\Scripts\activate.bat  # Windows
source venv/bin/activate  # Linux
```
1.4. В корневой папке выполните:
```bash
pip install -r requirements.txt
```
Файл `requirements.txt` содержит все библиотеки, кроме PyTorch и torchvision (они будут добавлены отдельно).  

### 2. Установка PyTorch в зависимости от вашего оборудования
#### Вариант А: Только CPU (подходит для любого компьютера)

2.1. При необходимости удалите старые пакеты
```bash
pip uninstall torch torchvision -y
```

2.2. Выполните:
```bash
pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu
pip install torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cpu
```

#### Вариант Б: GPU (NVIDIA CUDA) - весит гораздо больше
2.1. Сначала определите, какая версия CUDA установлена в вашей системе.
- Откройте терминал и выполните команду:  
  ```bash
  nvidia-smi
  ```
  В верхней части вывода найдите строку `CUDA Version: X.Y` (например, `13.1`).
- Если команда не найдена или драйвер NVIDIA отсутствует, значит GPU не поддерживается — используйте вариант А (CPU).  
- Версия CUDA должна быть хотя бы `12.6`

2.2. При необходимости удалите старые пакеты
```bash
pip uninstall torch torchvision -y
```

2.3. Выполните:
```bash
pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cu126
pip install torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu126
```

### 3. Запуск приложения
Точка входа находится в корне репозитория:
```bash
python main.py
```

## Быстрый старт
1. **Архитектура:** Перетащите блоки из левой панели на холст. Соедините их портами. Настройте параметры в правой панели. Нажмите `Валидировать граф`.
2. **Обучение:** Перейдите на вкладку `Обучение`. Выберите датасет, настройте препроцессинг, оптимизатор и метрики. Нажмите `Далее`
3. **Мониторинг:** Нажмите `Старт` на вкладке `Мониторинг`. Следите за графиками, логами и таблицей метрик в реальном времени. Можно ставить на паузу или останавливать.
4. **Экспорт:** На вкладке `Экспорт` сгенерируйте Python-код модели/обучения или выгрузите веса в `.pth`.

## Структура проекта
```
neural-net-designer/
├── main.py                 # Точка входа
├── requirements.txt        # Базовые зависимости (без PyTorch)
├── app/
│   ├── config.py           # Настройки приложения и пути
│   ├── core/               # Логика: узлы, компилятор графа, обучение, undo/redo
│   ├── export/             # Генераторы кода (Jinja2 + Black)
│   ├── ui/                 # Интерфейс: главное окно, вкладки, диалоги, виджеты
│   ├── templates/          # Jinja2 шаблоны для генерации кода
│   └── styles.qss          # Стили интерфейса
├── data/
│   ├── datasets/           # Загруженные датасеты (MNIST и др.)
│   └── projects/           # Сохранённые проекты (.nnd)
└── README.md
```

## Технологии
- **GUI:** `PyQt5`, `NodeGraphQt`, `pyqtgraph`
- **Backend ML:** `PyTorch`, `torchvision`, `scikit-learn`
- **Codegen:** `Jinja2`, `Black`
- **Архитектура:** MVC-подобная, многопоточное обучение через `QThread` + сигналы
